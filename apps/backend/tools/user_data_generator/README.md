# User Data Generator

Этот инструмент генерирует тестовых пользователей, объявления и пользовательские события и загружает их в PostgreSQL.

## Подготовка БД

Из корня репозитория можно поднять PostgreSQL и применить миграции:

```bash
make db-setup
```

Если нужно только поднять сервисы вручную:

```bash
docker compose up -d postgres
make migrate-up
```

## Запуск генератора

Из папки backend:

```bash
go run ./tools/user_data_generator -dsn "postgres://avito-recap:avito-recap@localhost:5433/avito-recap?sslmode=disable" -users 50 -listings 200
```

## Параметры

- `-dsn` — строка подключения к PostgreSQL
- `-users` — количество пользователей
- `-listings` — количество объявлений
- `-seed` — seed для воспроизводимой генерации

## Алгоритм генерации

1. Генерация пользователей.
   - Для каждого пользователя создаётся профиль с ценовым сегментом: budget, mid или premium.
   - У пользователя есть предпочтительные и менее вероятные категории.
   - Время регистрации формируется в прошлом.

2. Генерация объявлений.
   - Категория выбирается с учётом весов, заданных в конфиге.
   - Цена берётся из диапазона категории.
   - Время публикации и закрытия выбирается в пределах окна.
   - Объявления получают только категорию, цену, наличие доставки и время публикации; региональные ограничения больше не используются.

3. Генерация событий поведения.
   - Для пользователя выбирается текущая категория интереса и ориентировочная цена.
   - Из доступных листингов формируется пул кандидатов и постепенно сужается.
   - Затем генерируются действия в порядке: поиск → просмотр → избранное → контакт → сделка → отзыв.
   - Вероятности шагов зависят от профиля пользователя и характеристик категории:
     - `ReturnRate` — как часто пользователи возвращаются к категории;
     - `PurchaseVolume` — насколько активно категория приводит к покупкам.

## Данные и поведение

- Пользователи: разные профили поведения, ценовые сегменты и предпочтения по категориям.
- Объявления: категории, цены, время публикации, доступность доставки.
- События: поисковые запросы, просмотры, добавления в избранное, контакты, сделки и отзывы.
